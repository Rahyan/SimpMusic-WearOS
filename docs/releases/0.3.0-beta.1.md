# 0.3.0-beta.1

SimpMusic for Wear OS, with standalone watch playback and an Android companion for signing in and controlling your watch from your phone.

## What's included

- Browse and search YouTube Music directly on the watch, with access to albums, artists, playlists and your library.
- An artwork-backed player with circular progress, seeking, audio output controls and bezel volume adjustment. Swipe up for playback controls, lyrics and the queue.
- An Android companion for sign-in, playback controls, seeking, queue management and offline queue preparation.
- Individual track downloads and offline queues of up to 100 tracks. Files are checked for completeness before offline playback.
- Keep up to eight playlists offline, with up to 100 tracks each. Automatic refresh follows the watch's download policy, with an estimated storage budget and optional cleanup that protects manual downloads and queued music.
- A playback tile and watch-face complication.
- Separate ARMv7 and ARM64 watch APKs, plus a universal ARM option.

## Fixes

- Improved queue restoration, shuffle and Play next ordering.
- Reject stale remote commands when the current track or queue has changed.
- Preserve watch downloads, history and local library changes during phone synchronization.
- Update the companion's playback time and seek slider between watch updates.
- Reject incomplete file transfers instead of reporting them as finished.
- Improve phone-initiated playback when the watch app is closed, and allow the media service to reconnect after becoming idle.
- Reduce startup work and background overhead from tiles and complications.

## Which APK?

| File ending | Install on |
| --- | --- |
| `WearOS-0.3.0-beta.1-armeabi-v7a.apk` | Watches reporting `armeabi-v7a`, including the Galaxy Watch4 Classic |
| `WearOS-0.3.0-beta.1-arm64-v8a.apk` | Watches reporting `arm64-v8a` |
| `WearOS-0.3.0-beta.1-arm-universal.apk` | Either ARM ABI; larger download |
| `Companion-0.3.0-beta.1.apk` | Your paired Android phone, Android 8.0 or newer |

Filenames start with `SimpMusic-`. Install one watch APK and the companion from the same release. Check your watch with `adb -s <watch-id> shell getprop ro.product.cpu.abilist`; a 64-bit CPU does not always mean 64-bit Android. These are complete APKs, not split APK sets. Do not install a watch APK on your phone.

The optional full phone app can be built from source. It replaces the lightweight companion on the same package channel.

## Install or update

1. Install the watch APK using wireless ADB, then install the companion on your paired phone.
2. Open the companion, sign in, then choose **Accounts → Sync session from phone** on the watch. Guest playback is also available.
3. Choose music on the watch. The companion follows that watch's player and queue.

Use `adb install -r` to update an install with the same package and signing key. If Android reports a signature mismatch, keep the old app installed until you have backed up anything you need. Uninstalling deletes local data.

Release builds use `io.github.rahyan.simpmusicwear`. Debug builds add `.dev` and do not share their library or downloads with release builds.

This fork can be installed alongside upstream SimpMusic. Builds using the older `com.maxrave.simpmusic` package, including development variants, remain separate installs. Their sign-in, library and downloads are not transferred automatically; sign in again and download the music you want in the new app.

Use `SHA256SUMS` to verify your downloads. `release-manifest.json` records the version, package, signing certificate and APK hashes.

## Known limits

Playback and sign-in depend on YouTube's services. Changes to those services can cause failures, and some tracks or restricted media may be unavailable.

For a bug report, include app version, watch/phone model, Android versions and steps to reproduce it. Do not attach cookies, access tokens, account databases or unredacted diagnostics.
