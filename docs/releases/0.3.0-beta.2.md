# 0.3.0-beta.2

**Updating from beta.1? Only update the companion on your phone. Your beta.1 watch app remains compatible, so you can keep it installed.**

## Companion fix

Fixes [#1](https://github.com/Rahyan/SimpMusic-WearOS/issues/1): the player could repeatedly show CONNECTING and briefly disable its controls even though the watch was still connected.

The companion now checks updates using its own response timer, so differences between the phone and watch clocks do not make fresh player updates look stale. Saved or duplicate updates cannot keep old controls active, and the playhead uses the same local timer. Sign-in is not required to use the controls.

Thanks to tgranz for the recording and for [confirming the test fix](https://github.com/Rahyan/SimpMusic-WearOS/issues/1#issuecomment-6842952954) on a CMF Phone 2 Pro and Galaxy Watch6 running Android 16.

## Update

Download `SimpMusic-Companion-0.3.0-beta.2.apk` and install it over the existing companion on your phone. No uninstall or fresh sign-in is needed. This also updates over `0.3.0-beta.2-test.1`.

The watch APKs are included for new installs and anyone who wants both apps on the same version. Watch functionality is unchanged in this release; updating an existing beta.1 watch is optional.

## New installs

Install the companion on your Android phone and one watch APK on the watch:

| APK | Device |
| --- | --- |
| `SimpMusic-Companion-0.3.0-beta.2.apk` | Phone, Android 8.0 or newer |
| `SimpMusic-WearOS-0.3.0-beta.2-armeabi-v7a.apk` | ARMv7 watch, including the Galaxy Watch4 Classic |
| `SimpMusic-WearOS-0.3.0-beta.2-arm64-v8a.apk` | ARM64 watch |
| `SimpMusic-WearOS-0.3.0-beta.2-arm-universal.apk` | Either ARM watch ABI; larger download |

Use the ABI reported by Android on the watch; a 64-bit processor does not always mean 64-bit Android. Each watch APK is a complete app. See [installation instructions](https://github.com/Rahyan/SimpMusic-WearOS#install-and-sign-in).

All APKs use the existing release package and signing key. `SHA256SUMS` and `release-manifest.json` provide checksums and build identity. Version code is 43, above both beta.1 and the test update.

## Known limits

Playback and sign-in still depend on YouTube's services. Automatic offline playlist refresh and cleanup remain experimental, with cleanup disabled by default. Broader device and Bluetooth headphone reconnect coverage remains limited. See the [beta.1 notes](https://github.com/Rahyan/SimpMusic-WearOS/releases/tag/v0.3.0-beta.1) for the existing feature overview and limitations.
